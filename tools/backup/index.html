把所有工具的数据打成一个文件，不用一个个点进去导。 换设备时在新手机上导入这一个文件就全回来了。

    这台设备上还没有任何工具数据
    先去用几下再回来备份
    Transfer

    换设备怎么做
    1. 在旧手机上打开这一页，点「一键导出全部」，得到一个 json 文件
    2. 把文件存到网盘，或者用微信发给自己，别只留在旧手机上
    3. 在新手机上打开工作台，进这一页点「一键导入恢复」，选那个文件
    4. 问合并还是替换时，新手机是空的，两个都行；替换更干净
    5. 回到各工具页面刷新一下，数据就在了

    数据只存在浏览器里。清除浏览器数据、删掉这个应用、或者 iOS 长时间不打开被系统清理，都会丢。建议每隔一段时间导一份存着。
